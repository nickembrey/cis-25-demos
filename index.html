CIS 25 Demos

Interactive visualizations for CIS 25: Object-Oriented Programming Using C++, Berkeley City College.

  • How a Stack WorksPush, pop, and peek on an IntStack, shown as a pile and as linked nodes in memory, one line of code at a time.
  • The Call StackStep through short programs and watch frames get pushed and popped, with parameters, local variables, and destructors.
  • Stack Memory and Heap MemoryFollow pointers from stack frames to heap blocks: new and delete, an IntStack's nodes, a memory leak, and a stack overflow.
  • Data Structure SimPush and pop on a stack, queues and deques, linked nodes in memory, and a step-through call stack.
